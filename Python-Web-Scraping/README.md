# Python Web Scraping
Built python web scraping projects to collect, analyze, and visualize online data, with outputs including CSV files and charts.

Technology: **Python, Requests, Selenium, Jieba, Pandas, Matplotlib**

## Web Scraping Workflow
1.Crawl specified structure of website.
2.Combine all text into one paragraph.
3.Remove punctuation and stopwords.
4.Use jieba for word segnientation.
5.Word frequency calculation.
6.Data visualization using matplotlib.
