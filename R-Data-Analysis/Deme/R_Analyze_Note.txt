# sample  → 抽樣
# round  → 四捨五入
# rnorm  → 常態分布（Normal distribution）
# runif  → 均勻分布（Uniform distribution）
# qnorm  → 查表
# pnorm  → 累積密度函數
# rbinom  → 二項分配（Binomial distribution）/伯努利分配（Bernoulli） 📌 應用：投硬幣、成功 / 失敗實驗、機率模擬；1 = 成功；0 = 失敗  # 模擬實驗
# rpois  → # 卜瓦松分配（Poisson distribution） 📌 常用於 事件發生次數：一小時來幾個客人、每天事故數、每分鐘電話數
# rexp  → exponation 指數分配 📌 常用於 等待時間：等下一個客人多久、機器故障前時間、事件間隔時間

# dbinom  → density 機率密度 👉 某個值的機率:剛好出現 6 次正面 的機率。  # P(X=6)
# pbinom  → probability 累積機率 👉 出現 6 次或以下正面 的機率  # P(X≤6)
# qbinom  → quantile 分位數 👉 找到 累積機率 ≥ 0.95 時的最小成功次數  # P(X≤8)≥0.95  # 找臨界值

# dnorm  → 標準常態分布（Standard Normal distribution）
# pnorm  → 累積機率
# qnorm  → 分位數（pnorm 的倒數）

# dexp(x=1, r=2)  → 機率密度函數（PDF）👉「某個點附近的密度」，x=1的密度值（不是機率）  f(x)=re^(−rx)，x≥0
# pexp(x=1, r=2)  → 累積分佈函數（CDF）👉「在時間 x 內發生」的機率，在1單位時間內發生的機率  P(X≤x)=1−e^(−rx)
# qexp(p=0.9, r=2)  → 反累積分佈（Quantile Function）👉「有 p 機率會在多久內發生」，90% 機率會在多久內發生 x=−[ln(1−p)​]/r
