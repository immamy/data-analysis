# R Data Analysis
Built with R and RStudio, this project demonstrates practical skills in read data, data preprocessing, statistical analysis, and data visualization using R.

Technology: **R, RStudio**

## Features
- read data
- data preprocessing
- statistical analysis
- data visualization using R

## Summary
- install.packages() & library() & datasets
- class() & typeof()

- ts() 👉🏼 時間序列分析 Time series analysis
- read.csv() 👉 讀取檔案 Read the file
- plot() 👉 圖表分析 Chart Analysis
